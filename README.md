# 🎪 超絶くだらない募金サイト

ふざけた人が「これは面白い！」と思って募金したくなるような、ユニークな募金サイトです。

**✨ 新機能: Stripe & PayPay決済に対応しました！**

## 🎯 コンセプト

善人を騙すのではなく、バカバカしい理由で募金を募ることで、見た人が笑顔になり、「これなら応援したい！」と思えるサイトを目指しています。

## 🌟 特徴

### ユニークな募金理由
- 🍜 ラーメン二郎を全店制覇したい
- 🐱 猫に話しかけられたい
- 😴 世界一の昼寝スポットを探したい
- 💃 渋谷のスクランブル交差点で踊りたい
- 🛸 UFOを呼びたい
- 🥔 じゃがいもだけで1ヶ月生活したい

### インタラクティブな機能
- ✨ 美しいグラデーション背景
- 📊 リアルタイムで更新される進捗バー
- 💰 カウントアップアニメーション付きの統計表示
- 🎉 募金完了時のお祝いモーダル
- 📱 完全レスポンシブデザイン
- 🎮 隠しイースターエッグ（Konamiコード）

## 🚀 クイックスタート

### デモモード（決済なし）

ブラウザで `index.html` を開くだけで動作します（決済機能は動作しません）。

```bash
# Macの場合
open index.html

# Windowsの場合
start index.html

# Linuxの場合
xdg-open index.html
```

### 本格モード（決済機能あり）

実際の決済機能を使用する場合は、Node.jsサーバーを起動してください。

**詳細なセットアップ手順は [`SETUP.md`](SETUP.md) を参照してください。**

#### 簡易セットアップ

```bash
# 1. 依存関係をインストール
npm install

# 2. 環境変数を設定
cp .env.example .env
# .envファイルを編集してStripe APIキーを設定

# 3. サーバーを起動
npm start

# 4. ブラウザでアクセス
# http://localhost:3000
```

## 💳 決済システム

### 対応決済方法

✅ **クレジットカード（Stripe）**
- Visa、Mastercard、American Express、JCB対応
- 3Dセキュア認証対応
- テストモードで安全にテスト可能

✅ **PayPay（デモ実装）**
- PayPay決済に対応（要API設定）
- 現在はデモモードで動作

### セットアップ方法

詳細なセットアップ手順は **[`SETUP.md`](SETUP.md)** を参照してください。

#### Stripeテストカード

テストモードでは以下のカード番号を使用できます：

- **成功**: `4242 4242 4242 4242`
- **有効期限**: 任意の未来の日付（例：12/34）
- **CVC**: 任意の3桁（例：123）

### 決済手数料

- **Stripe**: 3.6% + ¥0（日本）
- **PayPay**: 要確認（契約による）

## 🎨 カスタマイズ

### 募金理由を追加する

`index.html`の`.donation-reasons`セクションに新しいカードを追加：

```html
<div class="reason-card" data-reason="your-reason">
    <div class="emoji">🎯</div>
    <h2>あなたの面白い理由</h2>
    <p>説明文をここに書く</p>
    <div class="progress">
        <div class="progress-bar" style="width: 0%"></div>
    </div>
    <p class="progress-text">¥0 / ¥10,000達成</p>
</div>
```

### 色を変更する

`style.css`の以下の部分を編集：

```css
/* メインカラー */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* アクセントカラー */
color: #667eea;
```
